# Bank logos

Drop an official logo here as `<slug>.svg` and the `BankBadge`
component auto-uses it instead of the brand-coloured monogram — no
code change needed.

Slugs (the `bank` enum): `golomt`, `khan`, `mbank`, `tdb`, `kkb`,
`cash`, `other`.

- Format: square `.svg` (the badge clips to a circle, `object-contain`).
- These trademarked assets are intentionally **not** committed; add
  the ones you have the right to use.
